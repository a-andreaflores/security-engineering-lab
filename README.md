# Security Engineering Lab

Hands-on cybersecurity lab focused on Linux security monitoring,
detection engineering, Python automation, incident investigation,
and AI-assisted security analysis.

## Objectives

- Build Linux security monitoring capabilities
- Analyze authentication and system logs
- Develop security detections
- Automate security analysis with Python
- Practice incident investigation
- Collect and analyze security telemetry
- Experiment with AI-assisted security investigations
- Develop practical skills relevant to Security Engineering and Detection Engineering

## Environment

- Host: Apple MacBook Air M5
- Hypervisor: VMware Fusion
- Linux VM: Ubuntu Server 26.04 LTS ARM64
- Hostname: ubuntu-lab
